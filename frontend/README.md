# HealthGuard AI - Frontend

Enterprise React 19 + TypeScript + Vite + Tailwind CSS v4 Frontend for Health Insurance Fraud Detection & SIU Investigation Platform.

## 🚀 Quick Start

1. Install dependencies:
   ```bash
   npm install
   ```

2. Run development server:
   ```bash
   npm run dev
   ```

3. Build for production:
   ```bash
   npm run build
   ```
